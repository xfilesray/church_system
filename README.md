# church_system

# ⛪ 教會事奉管理與恩典紀錄系統 (Church Ministry & Grace Management System)

專為教會同工、小組長與事工團隊設計的一站式系統，整合**恩典心得紀錄**、**場地借用預約**、**團隊事奉排班**以及**全欄位關鍵字查詢**功能。系統具備智慧防撞檢測（衝突預警）與強制儲存機制，確保聚會排班與場地調度順暢無阻。

---

## ✨ 系統核心功能 (Features)

1. **📖 恩典與體會紀錄 (Grace & Reflection Log)**
   - 紀錄同工個人服侍恩賜與經歷的恩典心得。
   - 專屬代禱事項欄位，促進團隊彼此關懷。

2. **🏠 場地借用與智慧防撞 (Venue Booking & Conflict Prevention)**
   - 支援主日大堂、副堂、各小組教室之預約借用。
   - **防撞檢測機制**：自動比對同日期、同時段之場地預約紀錄，若有衝突即時預警。
   - **強制儲存 (Force Save)**：彈性支援多個小組聯合借用或特殊聚會需求。

3. **📅 事奉排班時間表 (Ministry Roster Management)**
   - 支援講員、敬拜主領、音控/直播、招待、主日學等多元事奉崗位排班。
   - **下拉選單與動態同工名單**：自動導入已啟用的同工名單，選單快速排班。
   - **重複排班預警**：自動解析多同工輸入（支援中英文逗號 `,` `，` 及頓號 `、`），檢查「單次表單內部兼任」與「雲端資料庫同日同場次重複排班」。

4. **🔍 跨模組查詢與同工管理 (Query & Admin)**
   - **全欄位搜尋**：支援不限大小寫 (Case-insensitive) 與中英文關鍵字過濾。
   - **日期區間篩選**：可依聚會與事奉日期篩選歷史紀錄。
   - **CSV 資料導出**：一鍵下載匯出 UTF-8-SIG 格式之查詢結果。
   - **同工名單動態維護**：整合動態同工名冊，提升排班效率。

## 🏗️ 系統架構與模組解耦 (Architecture)

本系統嚴格遵循 **前後端語系解耦 (I18n Decoupling)** 與 **關注點分離 (Separation of Concerns)** 原則設計：

```text
.
├── app.py           # 主應用程式：介面元件配置與邏輯流程 (純英文變數，零 UTF-8 編碼衝突)
├── constants.py     # 語系設定檔：集中管理 UI 繁體中文標籤 (LABELS) 與下拉選單選項
├── database.py      # 資料庫抽象層：專責 Supabase CRUD 操作、衝突檢測與模糊查詢
├── requirements.txt # Python 依賴套件套件清單
└── README.md        # 專案說明文件
